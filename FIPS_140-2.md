# FIPS status

**OpenLit is not a FIPS 140-2 validated cryptographic module.**

Earlier documentation described approved algorithms as if they established
product compliance. That claim is not supported. A configuration field named
`fips_mode` or an internal self-test is not a validation certificate.

Some dependencies implement standardized algorithms. OpenLit also uses BLAKE3
and other components whose presence must be evaluated in any proposed validated
boundary. This project does not supply a certificate number, approved module
boundary, or validated operating environment.

If you need a validated product, do not treat OpenLit as one. See
[the cryptography guide](CRYPTOGRAPHY.md) for what the code uses and
[the FIPS 140-3 note](FIPS_140-3_COMPLIANCE.md) for the same limitation.
